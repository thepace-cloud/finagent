# FinAgent：公开语料多证据评测

这是与根目录原 `/chat` 服务并列的独立实验模块。12 份中国银行产品页面保留 URL、抓取时间、原始内容哈希和段落定位；66 题按问题组分为 30 题开发集、36 题保留集。题目由 AI 草拟并核对来源，未声称人工标注。

候选方法按产品和问题条件拆解检索，合并去重；缺参先追问，明确参数的等额本息月供由代码计算。与基线同样最多给生成模型 6 段证据。保留集必要证据全覆盖由 15/19 到 19/19，字段、状态和引文的自动检查由 28/36 到 34/36。具体限制和失败例见 [REPORT.md](REPORT.md)。

## 运行

从仓库根目录按主 README 准备 Python 环境、`models/pmml12/` 本地嵌入模型和私有 `.env` 中的模型 API 凭据。进入本目录后运行：

```powershell
python -m unittest test_public test_api -v
python -m uvicorn app:app --host 127.0.0.1 --port 8001
```

向 `POST /answer` 发送 `question`，可选 `requested_fields` 指定需要的结构化字段。原始来源页面可能过时，此实验不能提供实时贷款条件或审批建议。该模块未做公网部署或真实用户验收。
