## ① 市场调研数字（09-26 交）

**目的**：文档§二"可行性分析"和§一"概述"目前缺真实市场数据支撑，补上后"目标群体"一节从"我们觉得"变成"数据说"。

**要什么**：3–5 个数字，每个必须有**来源机构 + 报告名 + 数据年份**（评审可查证，不可用自媒体转述）。

建议方向（按优先级）：

1. **个人贷款规模**：央行《金融机构贷款投向统计报告》——个人住房贷款/个人消费贷款余额（证明"贷款是大众决策"）；
2. **金融素养水平**：央行《消费者金融素养调查分析报告》——消费者金融素养得分或"不理解贷款术语"的比例（证明"普通人读不动贷款文档"）;
3. **移动上网习惯**：CNNIC《中国互联网络发展状况统计报告》——手机网民规模/占比（证明"手机浏览器即开即用"的合理性）。

**交付格式**：每个数字一行——`数字 + 一句话解读 + 来源（机构/报告/年份）`。A 会把它们嵌进文档对应段落，并加脚注。
